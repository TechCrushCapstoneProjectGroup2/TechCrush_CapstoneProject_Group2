# Project charter

Keeps the whole team aligned on the client problem before implementation starts.

- `brief-summary.md` - the client scenario, stated requirements, and the contradiction we must resolve.
- `scope-and-constraints.md` - hard boundaries: private-by-default, expiring unguessable links, full audit trail, low cost, non-technical operator, public access rule.
- `team-and-roles.md` - who owns which area and who reviews it.
