# Documentation index

Read in this order:

1. `00-project-charter/` - what the client asked for and the constraints.
2. `01-design/` - the Phase 0 worksheet and ADRs that record our decisions.
3. `02-architecture/` - what we built and how data moves.
4. `03-runbooks/` - how to deploy, operate, revoke, respond and tear down.
5. `04-incident-reports/` - required report for the injected/observed failure.
6. `05-meetings/` - decisions and action items.
7. `06-demo/` - the live demo script and presentation outline.

Implementation lives in:

- `deploy/` - deployment and teardown scripts.
- `scripts/` - CLI tool.
- `tests/` - end-to-end verification and evidence helpers.

Rule: if a decision is not written down here, it is not a design - it is an accident.
