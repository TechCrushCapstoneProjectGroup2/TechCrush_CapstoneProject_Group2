# Runbooks

Task-focused instructions. Each runbook should be executable by any team member, not just its author.

- `setup-local.md` - prerequisites, `.env`, CLI login.
- `deploy.md` - run the automated end-to-end deployment.
- `operations.md` - **plain English** guide for the office manager.
- `revoke-share.md` - early revocation and verification.
- `log-review.md` - how to read the audit trail.
- `incident-response.md` - what to do when something breaks.
- `teardown.md` - remove all billable resources.
