# Architecture decision records (ADRs)

One decision per file. Keep them short and final once accepted.

- `ADR-001-access-mechanism.md` - how anonymous access works without a public container.
- `ADR-002-expiry-and-revocation.md` - default TTL, max TTL, and early revocation.
- `ADR-003-logging.md` - audit log fields, destination, retention, access, redaction.

Use `_ADR-TEMPLATE.md` when adding a new decision.
