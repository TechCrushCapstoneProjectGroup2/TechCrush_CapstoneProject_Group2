# Incident reports

The brief requires an incident report for every project after deployment is verified and demoed.

- Copy `_TEMPLATE.md` to `YYYY-MM-DD-<short-title>.md`.
- Mandatory sections: **Symptom**, **Investigation trail**, **Root cause**, **Fix**, **Design reflection**.
- Link the screenshots/logs in `evidence/` from the relevant section.
- The design reflection must discuss the design, not just the fix: did Phase 0 make the failure more/less likely or easier/harder to catch, and what would you change?
