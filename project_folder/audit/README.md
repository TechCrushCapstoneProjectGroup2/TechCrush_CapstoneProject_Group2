# Audit trail

The audit trail is a first-class deliverable, not an afterthought.

- `schema.md` - exact fields every record must contain.
- `retention-and-access.md` - retention period, readers, writers, tamper resistance.
- `samples/` - redacted log sample covering one full upload-to-share cycle (required by the brief).

Rule: an action that is not logged did not happen, as far as the demo is concerned.
